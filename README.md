# _hillel friedman

אתר סטטי בעברית: עמוד פתיחה (index.html) וחמישה משחקי דפדפן — מבוך, טטריס, סנייק, ראנר (רץ), דודלג'אמפ. בכל המשחקים האדם מהתמונות (`assets/face.png`) הוא השחקן.

## הרצה מקומית

```sh
python -m http.server 8124 --bind 127.0.0.1
```

then open `http://127.0.0.1:8124/`.

## מבנה

- `index.html` — עמוד פתיחה עם כרטיסים למשחקים.
- `maze.html` — מבוך בשלושה שלבים (חצים).
- `tetris.html` — טטריס (חצים + רווח hard drop).
- `snake.html` — סנייק (חצים/WASD, כפתורי מהירות).
- `runner.html` — רץ אינסופי (רווח/חץ למעלה לקפיצה).
- `doodle.html` — דודלג'אמפ (חצים/החלקה).
- `build_hero.py` — סקריפט PIL ליצירת `assets/hero.png`.
- `assets/` — תמונות ואריחים.

## מקשים

| משחק | התחלת משחק | שליטה |
|---|---|---|
| מבוך | לחיצה על "התחל" | חצים |
| טטריס | לחיצה על "התחל" | ← → ↓ ↑, רווח = hard drop |
| סנייק | לחיצה על "התחל" | חצים / WASD |
| ראנר | כל מקש | רווח / חץ למעלה = קפיצה |
| דודלג'אמפ | לחיצה על "התחל" | ← → / החלקה |

## הערות

- אין תלויות חיצוניות חוץ מ-Python + PIL (build_hero.py).
- כל המשחקים פועלים ללא שרת aside from the static file server.
